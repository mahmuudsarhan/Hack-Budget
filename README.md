# hack budget

Running a hackathon is great. Managing event expenses in a soul-crushing spreadsheet at 2 AM is not.

Hack Budget handles the boring math so you can focus on buying boba, stickers, and questionable event supplies.

## features

- **auto-math:** calculates turnout, per-attendee cost, and remaining stash in real time
- **panic mode:** dynamic UI alerts when you inevitably go over budget
- **local persistence:** auto-saves to `localStorage` so an accidental refresh won't ruin your day
- **nuke button:** 1-click wipe to start over from scratch
- **zero bloat:** single static HTML file, zero dependencies, pure dark mode

## quickstart

1. clone or download `index.html`
2. open it in any browser
3. that is literally it
